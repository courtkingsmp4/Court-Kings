# COURT KINGS

A fast 1v1 basketball browser game. Single HTML file, no install, no dependencies.

**Modes:** Quick Match, Practice, Tournament, and local 2 Players on one keyboard.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | Left / Right arrows |
| Jump | W | Up arrow |
| Sprint | Left Shift | Right Shift |
| Shoot (hold to charge) | F | J |
| Dunk (near the rim) | R | I |
| Steal | G | K |
| Block | V | L |
| Ability | E | U |

In solo modes either set of keys works, and Space also jumps. Esc pauses.

## Play

Open `index.html` in a browser, or play it online via GitHub Pages.
